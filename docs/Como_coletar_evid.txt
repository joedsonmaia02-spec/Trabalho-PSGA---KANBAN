Aba Projects: se houver um quadro com colunas como To do, In progress e Done, e a visualização em board, é o indício mais forte. Use o gh CLI para listar:


gh project list --owner NOME_DA_ORG


Labels de fluxo: como in progress, blocked, ready, wip, ou um label kanban


Templates e arquivos de configuração: pastas .github/ISSUE_TEMPLATE, .github/workflows com automações de quadro, ou documentação no README e CONTRIBUTING.md mencionando Kanban.

Histórico de issues e PRs: procure por issues fechadas automaticamente quando o PR é mesclado, o que indica integração entre código e quadro.
