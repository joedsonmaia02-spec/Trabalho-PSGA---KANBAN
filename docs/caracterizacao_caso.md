# Caracterização do Caso Real: Querido Diário

## 1. Visão Geral do Projeto
* **Projeto:** Querido Diário (`okfn-brasil/querido-diario`)
* **Organização:** Open Knowledge Brasil (OKBR)
* **Objetivo:** Democratizar o acesso aos diários oficiais dos municípios brasileiros através do desenvolvimento de raspadores de dados (scrapers) em código aberto, centralizando documentos públicos para facilitar a busca e o controle social.
* **Repositório Oficial:** [https://github.com/okfn-brasil/querido-diario](https://github.com/okfn-brasil/querido-diario)

## 2. Métricas e Comunidade (Visão Geral Open Source)
* **Stack Tecnológica:** Python, Scrapy, etc.
* **Engajamento:** 1.4k stars, 484 forks, 134 contribuidores.
* **Atividade de Desenvolvimento:** Frequência de commits esporádica (por demanda), 418 issues fechadas, 602 pull requests integrados.
